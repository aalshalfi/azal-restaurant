# AZAL Restaurant Website — first draft

Responsive one-location restaurant website starter built around the supplied AZAL logo and brand palette.

## Included
- Homepage, story, menu placeholder, and visit/location sections
- Responsive mobile navigation
- Supplied logo asset
- No invented street address, opening hours, menu items, or order links

## Run locally
Open `index.html` in a browser.
